# Clarisights

> Clarisights is an enterprise marketing analytics platform that unifies marketing data from channels, analytics, attribution, and warehouse sources into a single self-service platform, so marketing teams can explore data, build dashboards, and get trustworthy insights without SQL or a data team. It also ships a Marketing Data MCP server that connects governed marketing data to AI tools (Claude, ChatGPT, Cursor, Gemini).

## AI / Agent access
- [Marketing Data MCP](https://clarisights.com/marketing-data-mcp): Remote MCP server; workspace-scoped connection URL from clarisights.com/dashboard/mcp-settings, authenticated with your Clarisights login, governed by workspace ACL. Tools: list_data_sources, list_metrics, list_dimensions, query_data, list_reports, get_report.
- [MCP manifest (this repo)](mcp/clarisights-mcp.yml)
